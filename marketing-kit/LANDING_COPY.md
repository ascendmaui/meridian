## Features

### Interactive 3D visualization

The development-branch page is titled Meridian Globe. Its description is “Meridian Globe Experience - Interactive 3D visualization.”

### A globe that fills the window

The globe container is the full browser window. The running scene paints a sky-blue background and a deep-sky-blue sphere, and the sphere rotates.

### A skip link to the visualization

The page includes a skip link with the text “Skip to globe visualization.” The globe region is labeled “3D globe visualization.”

### Owned by Ascend Maui

The repository README names Ascend Maui (`ascendmaui/meridian`) as the owner and calls that repository the durable source of truth.

## FAQ

### What is Meridian?

Meridian is a hosted interactive globe experience from Ascend Maui.

### Where does the project live?

https://github.com/ascendmaui/meridian is the durable source of truth.

### What does the globe client show?

On development branches the client is a Three.js scene: sky-blue background `#87CEEB`, deep-sky-blue sphere `#00BFFF`, and a slow rotation. Before the scene starts, the page background is `#F0F0F0` and the loading line reads “Loading globe visualization…”.

### What is on the default branch today?

The README states that application source and deploy config will land in the repository as the product is recovered and rebuilt.

### Is a production URL published?

The repository does not publish a production URL. The call to action is the repository itself.

### What is Meridian based on?

Meridian is Ascend Maui’s rebrand of an MIT-licensed open-source globe. Public copy uses the Meridian name.

### Which license is declared?

Development branches set `"license": "MIT"` in `package.json`. The default branch does not yet include a LICENSE file.

### Does the globe page collect an account?

The development-branch page has no account form. `llms.txt` on those branches says the page collects no user data.

### Are there customer quotes or usage figures?

The repository does not include customer quotations or usage figures. This page does not add any.
