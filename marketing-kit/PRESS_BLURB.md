## Standard

Meridian is a hosted interactive globe experience from Ascend Maui. The GitHub repository ascendmaui/meridian is the durable source of truth for the product. Meridian is a rebrand of an MIT-licensed open-source globe; public materials use the Meridian name.

On development branches, the globe page is titled Meridian Globe and described as an interactive 3D visualization. It is a browser page: a Three.js scene with a rotating sphere, a skip link to the visualization, and no account form.

The README states that application source and deploy config will land in the repository as the product is recovered and rebuilt.
