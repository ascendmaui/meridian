## What the pictures show

The mark uses the sphere color `#00BFFF`, the scene background `#87CEEB`, and the black and gray values from the globe page. Store screens show that scene inside an iPhone frame and a Mac window titled “Meridian Globe”. They are drawn templates, not photos of a running build.

## Copy

The description line used on images is the README line: “Hosted interactive globe experience.” Landing, social, and press files repeat only claims that file can source. See `STYLE_GUIDE.md` for the color and type provenance.
